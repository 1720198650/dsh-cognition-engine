# 认知引擎 · 使用说明书（小白版）

> 版本：0.13.0 已发布功能 + 本地已开发未发布功能（会标"未发布"）。
> 一句话：**它给 AI 配了一本"记账式的记忆本"和一本"带证据的规矩本"，并且会告诉你它记住了什么、凭什么这么记。**

---

## 一、它解决什么问题

普通 AI 有三个毛病：

1. **记不住**——聊完这次，下次全忘；
2. **记错也不知道**——把道听途说当真事，还把旧结论和新结论混在一起；
3. **你说一遍它不改**——你说"不对，是北京不是上海"，下次它还写上海。

这个插件就是修这三个毛病：

| 毛病 | 它怎么修 |
|---|---|
| 记不住 | 把重要的事写进本地文件（不是存在模型脑子里），下次自动带进对话 |
| 记错不知道 | 每条记忆都记"来源、时间、什么时候失效"；被推翻的旧记不删除，标为"已失效" |
| 不改 | 你说"错了"，它把旧记录标"已失效"，新记录标"自这条起生效"，并且**不会两边都当真** |

---

## 二、怎么打开

1. 这个插件已经装在你的 DSH 里，**不用额外操作**。
2. 在对话输入框下方有一个**小图标**（插件停靠栏），点开就是面板。
3. 面板上有九个页签：**记忆 / 主题 / 准则 / 人格 / 超级代理 / 收件 / 沉积 / 学习 / 设置**。

> 面板每 5 秒左右自动刷新一次；显示"无数据"说明还没连上，换个标签页再回来通常就好。

---

## 三、九个页签，分别是什么

### 1. 记忆 —— 她知道的事

- **看什么**：一条条"事实"。每条形如「部署区域在上海机房」。
- **每条背后的信息**：重要度、来源（你说的 / 她自己记的 / 从收件箱采用的）、什么时候开始的、是否已失效。
- **能做**：改内容、删、标"已被哪条取代"、按主题筛。
- **重要规则**：**删除是打标记，不是真删**。所以删错了还能找回来。
- **你什么时候用它**：想确认"她到底记了我什么"，或者发现记错了。

### 2. 主题 —— 自动分类

- **看什么**：系统自动把相近的记忆归成一组（比如"发布流程""插件架构"）。
- **能做**：新建/停用主题；每个主题下直接加待办；**重建 wiki**（见第 7 节）。
- **提示**：记忆少于 10 条时，主题基本是空的，这是正常的。

### 3. 准则 —— 她的"工作规矩"

- **看什么**：一条条规矩，比如「发版前必须跑真实入口」。
- **每条必须写**：内容 + **适用边界**（什么情况下**不**适用）。没写边界的提交不了。
- **能做**：新增（要审批）、停用、看它被用过几次、对不对（helpful / harmful）。
- **为什么不能直接生效**：准则会改变她的行为，所以**必须你点头**。她自己产出的只是"候选"。

### 4. 人格 —— 她是谁

- **看什么**：一段固定的人格描述（比如"说话直接，结论在前"）。这段会一直随对话生效。
- **能做**：编辑、改字数上限、锁定不想被改的短语。
- **注意**：这是**设定**，不是"经历长出来的"。真"长出来"的东西在「沉积」页。

### 5. 超级代理 —— 长任务外包

- **看什么**：把长任务丢给另一个代理去跑，面板上看它的总览和工单。
- **能做**：建工单、推进状态、填产物。
- **什么时候用**：一件事要跑很久、步骤很多，不想占着当前对话。

### 6. 收件 —— 外部材料先进这里（未发布）

- **看什么**：你粘贴进来的链接/摘录，状态是"待审"。
- **能做**：**采用**（变成记忆）或**丢弃**。
- **为什么多这一步**：网上的东西不能直接信。它先自动查重（完全一样 / 差不多 / 和已有记忆重复），重复的直接标出来。
- **重要**：**采用必须你亲手点**，没有"全选采用"。

### 7. 沉积 —— 她的"经历"（未发布，观察期）

- **看什么**：日志——哪一次"翻案"让她的倾向变了多少。
- **能做**：
  - 输入一个主题，点「看看」= **视角窗**：她此刻会先注意到什么、会忽略什么、什么姿态；
  - 点「自检」：只告诉你"有没有偏移"，**不给数字**；
  - 看事件日志。
- **为什么不给数字**：数字一旦给你，你就会去调，它就从"经历"变成"配置"了。
- **诚实提醒**：这个模块还在**观察期**，目前只有 1 条事件。**到 11-25 若不足 5 条，按事先约定直接砍掉。**

### 8. 学习 —— 她从对话里学到什么

- **看什么**：准则被用了几次、用对没有；知识缺口（她卡住的地方）。
- **能做**：看缺口、手动触发检查。
- **提示**：这一页的数字只有在真的用起来之后才会有意义，刚装的时候全 0 正常。

### 9. 设置 —— 开关和路径

- **看什么**：注入开关、预算、各种文件路径、口令。
- **能做**：关掉注入（只手动问她）、设访问口令（同机其他程序就进不来）、改数据文件位置。
- **建议**：**除非你知道自己在改什么，这页别动。**

## 四、她"自己会做"的八件事（不用你指挥）

| 能力 | 说什么 | 你什么时候会感觉到 |
|---|---|---|
| `cognition_remember` | 记一条事实，可以顺便让旧的失效 | 你说"记住…"或"改一下…" |
| `cognition_recall` | 翻记忆（可按严格/历史/当时以为/联想四种口径） | 她回答里带上"根据你之前说的…" |
| `cognition_context` | 开场先看一遍：核心记忆 + 各主题进展 | 新对话第一句她就"知道"你的背景 |
| `cognition_reflect` | 三段式反思：正题 → 反题 → 合题 | 你说"复盘一下""想清楚这件事" |
| `cognition_state` | 报自己的状态（多少条记忆/准则/主题） | 你问"你现在记得多少" |
| `cognition_forget` | 删（其实是打标记） | 你说"忘掉这条" |
| `cognition_clarify` | **开工前先问一句**，防止她自作主张 | 需求含糊时，她会先问一个问题 |
| `manage_long_task` | 建/推进/完结长任务；**标"完成"必须有证据** | 你说"这事先做一半，明天继续" |

> 最后一条的"必须有证据"不是刁难：模型很容易把"做了一半"说成"已完成"，所以它被要求给出能核对的东西（文件路径、命令输出、链接）。

## 五、自动发生的六件事

1. **开场注入**：每次对话开始，自动把"人格 + 准则 + 待补缺口"放进她的提示里（你看不到，也不占对话记录）。
2. **反馈回写**：你说"不对"或"对"，系统会给刚用过的准则记一笔成功/失败。
3. **定时巡视**：每 3 小时看一眼有没有拖太久的任务。
4. **自动归档**：180 天没被想起来的记忆，退出"严格召回"（**不删**）。
5. **离线整合（dreaming）**：找三类问题——重复的活记忆、没归主题的准则、证据已失效的准则。**只报告，不改数据**。
6. **wiki 增量维护**（未发布，默认关）：主题页内容变了才更新，没变化不写文件；你手改过的段落不会被覆盖。

## 六、数据在哪、怎么备份

全部在本机，**不上传、不联网**（除了「收件」你手动粘贴内容时是你自己给的）：

```
C:\Users\<你>\.dsh\cognition-engine\
  cognition-state.json      记忆（最重要）
  cognition-playbook.json   准则
  cognition-topics.json     主题
  cognition-persona.json    人格
  tasks.json                任务
  wiki\                     主题 wiki
  cognition-inbox.json      收件箱
  .snapshots\               自动快照
```

**备份**：整个文件夹复制一份就行。
**恢复**：把文件夹换回去，重启 DSH。
**注意**：`cognition-state.json` 自带一份 `.sha256` 校验，被改动过会提示——这是故意的，不是故障。

## 七、六个常见问题

**Q1：她会不会乱记？**
不会自动乱记。记忆要么是你说的，要么是她明确判断值得记的；**收件箱里的东西不采用就不算记忆**。

**Q2：我删掉的东西能恢复吗？**
能。删除是打标记（`deletedAt`），文件里还在；面板上有"孤儿/修复"入口。

**Q3：为什么准则不能直接写进去？**
因为准则会改变行为，而模型自己说"这条准则很好"不算数（有研究证明模型自我批评反而更差）。所以必须人批。

**Q4：为什么她有时候先问一句再动手？**
这是 `cognition_clarify` 在工作：需求含糊时先确认，避免白干。

**Q5：面板某一页空白？**
先换页签再回来；还不行就告诉我，可能是版本不匹配（之前出过一次，是我的 bug）。

**Q6：会不会很贵？**
不会。注入的是摘要不是全文；注入渲染还做了缓存（实测 11ms → 1.5ms）。真正花钱的只有你主动让她"反思"或"蒸馏准则"时。

## 八、六个必须知道的限制

1. **默认很多东西是关的**：注入默认按需、沉积层影子模式、wiki 增量默认关。想用要手动开。
2. **准则必须写边界**，否则提交不了——这是刚加的规定。
3. **沉积层还没验证**：只有 1 条事件，11-25 见分晓，不足就砍。
4. **收件箱之后的能力（自动抓网页）没做**：需要开网络权限，且要你先证明会审。
5. **它不生成人格文案**：人格是设定（第 4 页），经历是倾向（第 7 页），两者分开。
6. **面板不显示"她的人格参数"**：这是设计，不是没做。理由见第 7 页说明。

| 看系统健康 | 学习（缺口）、沉积（自检） |
| 关掉自动注入 | 设置 |
| 备份 | 复制 `.dsh\cognition-engine` 文件夹 |
