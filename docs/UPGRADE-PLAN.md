## 五、明确不做

1. 向量库 / 图数据库 / SQLite（零依赖纯 JSON 是硬约束）。
2. 自动改人格/自动改四维（采集不产生熏习）。
3. 人格画像 / 参数面板 / 人格评分（违反宪章）。
4. 与 dsh-fish 在"记忆广度"上正面竞争。
5. 不把未同行评审的效果数字当依据。
