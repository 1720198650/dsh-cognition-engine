## 十一、成本策略（2026-11-17）

个人经费有限，默认按最省走：

| 措施 | 状态 |
|---|---|
| 注入默认**索引模式**（只给 `[id] 标题`） | ✅ 已改成默认，实测 697 → 348 字（约 -50%） |
| 注入渲染缓存（P2） | ✅ 11ms → 1.5ms |
| 只用确定性路径：收件判重、wiki 重建、概念归族 | ✅ |
| 模型调用只在三处：反思（手动）、蒸馏（手动）、翻案判定（仅在真实取代时） | ✅ |
| 用量看板 `/usage` + 设置页显示（字数/轮次/调用/估算金额） | ✅ |
| 概念层命名必须缓存（否则省 token 反而更贵） | 待 C1 |

口径：中文约 0.75 token/字；单价默认 ¥2/百万 tokens（可配 `pricePerMTokens`）。
**实测**：历史累计注入 193 万字 / 3067 轮 ≈ 145 万 tokens ≈ ¥2.9。
