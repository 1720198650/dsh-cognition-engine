# 我对这个插件的愿景

> 2026-11-17。不是路线图（那是 [UPGRADE-PLAN.md](UPGRADE-PLAN.md)），是"它最后应该是什么"。

## 一、一句话

**它应该成为一层"能说清自己凭什么、并且改不回去的"认知底座。**
不是更聪明的助手，是**可追责的记忆与倾向**。

## 二、三本账

这个插件从头到尾只在做三件事，对应三本账：

| 账本 | 记什么 | 判据 |
|---|---|---|
| **记忆（真）** | 什么是真的、什么时候不真了 | 双时态：任何一条都能回答"当时以为什么" |
| **准则（该）** | 什么该做、在什么范围内该做 | 每条带证据 + 带边界，无边界不许生效 |
| **倾向（偏）** | 被经历磨出来的起点 | 四维，哈希链，改一行就断 |

**三本账单向流动：记忆 → 准则 → 倾向。永不互相改写。**

这不是洁癖。是唯一能让"她为什么这么说"被回答的结构。

## 三、它不该是什么

- **不是通用长期记忆产品**。Hy-Memory 有 2067 星、三篇论文、30B 专用模型，那条路我们赢不了，也不该走。
- **不是人格编辑器**。给滑块让人调性格，一调就变成角色扮演。
- **不是意识宣传**。任何"她有内在体验"的说法都是骗人，我不写，也不让别人替我写。
- **不是代码生成器**。PyBot 那种 63 万行生成代码，是负债不是资产。

## 四、差异化只有一条，但足够深

别人能做的：更大的记忆、更多的后端、更多的模型。
**我们只做一件事：可验证。**

- 事件流有哈希链，改一个字就断；
- 每条准则有证据、有边界、有决策历史；
- 倾向的每一次变化都能指到"哪一次翻案"；
- 关键功能都做过**消融**：关掉它，效果必须消失（否则就是装饰）。

**可验证性不能让人惊艳，但能让人信任。** 而信任是这类东西唯一的价值。

## 五、三个"到 2027 年应该成立"的判断

1. **它能给别的记忆系统做体检**（M2 已经开头）。
   任何事件流 agent，我们都能算锚、出统计、做消融。这是外延最大的方向。
2. **它的准则本可以被别的插件复用**。
   准则 = 带边界、带证据、带决策历史的规则集——这个结构比"prompt 里写几句话"强得多。
3. **它的"倾向层"要么成立，要么被砍**。
   11-25 就是第一个裁决点：不足 5 条事件就砍掉。**我接受它可能不成立。**

## 六、成功与失败的判据（对称的，不许自欺）

| 算成功 | 算失败 |
|---|---|
| 两周后你能指着一条日志说"就是这件事之后她变了" | 参数变了但你说没差别 |
| 关掉某个功能，效果明显消失（消融成立） | 关掉和不关掉一样（那就是装饰） |
| 审计时能回答"这条结论凭什么" | 只能回答"模型当时觉得" |
| 三年后这套 JSON 还能被读、被迁移、被审计 | 依赖某个服务或某个模型版本才能跑 |

## 七、底线

**这个插件里，我不做"更好听的谎"。**
- 没验证就写"没验证"，不写"已完成"；
- 不知道就说不知道，不编文献；
- 用户指出的错，先承认，再修。

一个记录"什么是真的"的系统，自己先不能说假话。这是它能不能立住的前提。
