# 我对这个插件的愿景

> 2026-11-17。不是路线图（那是 [UPGRADE-PLAN.md](UPGRADE-PLAN.md)），是"它最后应该是什么"。

## 一、一句话

**它应该成为一层"能说清自己凭什么、并且改不回去的"认知底座。**
不是更聪明的助手，是**可追责的记忆与倾向**。

## 二、三本账

这个插件从头到尾只在做三件事，对应三本账：

| 账本 | 记什么 | 判据 |
|---|---|---|
| **记忆（真）** | 什么是真的、什么时候不真了 | 双时态：任何一条都能回答"当时以为什么" |
| **准则（该）** | 什么该做、在什么范围内该做 | 每条带证据 + 带边界，无边界不许生效 |
| **倾向（偏）** | 被经历磨出来的起点 | 四维，哈希链，改一行就断 |

**三本账单向流动：记忆 → 准则 → 倾向。永不互相改写。**

这不是洁癖。是唯一能让"她为什么这么说"被回答的结构。

## 三、它不该是什么

- **不是通用长期记忆产品**。Hy-Memory 有 2067 星、三篇论文、30B 专用模型，那条路我们赢不了，也不该走。
- **不是人格编辑器**。给滑块让人调性格，一调就变成角色扮演。
- **不是意识宣传**。任何"她有内在体验"的说法都是骗人，我不写，也不让别人替我写。
- **不是代码生成器**。PyBot 那种 63 万行生成代码，是负债不是资产。

## 四、差异化只有一条，但足够深

别人能做的：更大的记忆、更多的后端、更多的模型。
**我们只做一件事：可验证。**

- 事件流有哈希链，改一个字就断；
- 每条准则有证据、有边界、有决策历史；
- 倾向的每一次变化都能指到"哪一次翻案"；
- 关键功能都做过**消融**：关掉它，效果必须消失（否则就是装饰）。

**可验证性不能让人惊艳，但能让人信任。** 而信任是这类东西唯一的价值。

## 五、三个"到 2027 年应该成立"的判断

1. **它能给别的记忆系统做体检**（M2 已经开头）。
   任何事件流 agent，我们都能算锚、出统计、做消融。这是外延最大的方向。
2. **它的准则本可以被别的插件复用**。
   准则 = 带边界、带证据、带决策历史的规则集——这个结构比"prompt 里写几句话"强得多。
3. **它的"倾向层"要么成立，要么被砍**。
   11-25 就是第一个裁决点：不足 5 条事件就砍掉。**我接受它可能不成立。**

## 六、成功与失败的判据（对称的，不许自欺）

| 算成功 | 算失败 |
|---|---|
| 两周后你能指着一条日志说"就是这件事之后她变了" | 参数变了但你说没差别 |
| 关掉某个功能，效果明显消失（消融成立） | 关掉和不关掉一样（那就是装饰） |
| 审计时能回答"这条结论凭什么" | 只能回答"模型当时觉得" |
| 三年后这套 JSON 还能被读、被迁移、被审计 | 依赖某个服务或某个模型版本才能跑 |

## 七、底线

**这个插件里，我不做"更好听的谎"。**
- 没验证就写"没验证"，不写"已完成"；
- 不知道就说不知道，不编文献；
- 用户指出的错，先承认，再修。

一个记录"什么是真的"的系统，自己先不能说假话。这是它能不能立住的前提。

## 八、认知闭环：什么能收敛，什么不能（2026-11-17）

用户的期望（原话）：工作 → 反思 → 总结 → 用总结提升自己 → 更好地工作 → 再反思 → 再总结，
无尽地走下去，从相对真理逼近"绝对真理"。

### 8.1 可实现的闭环（这部分是真的）

```
工作（产出可核对的产物）
  → 证据（文件 / 测试 / 用户确认）
  → 诊断（哪里不对，为什么）
  → 候选（准则 / 概念 / 技能，带边界）
  → 试跑（在历史回合上验证，P4-2）
  → 人批（无边界不生效）
  → 更好的工作 …
```

四条不变量，缺一条就变成自激循环：

1. **无外部锚不进下一轮**（真跑一遍 / 有测试 / 用户确认，三者之一）
2. **每步留痕**（决策历史：诊断/证据/结果，P4-1）
3. **每步可回滚**（只追加，不删历史）
4. **每步可消融**（关掉这一步，效果必须消失；否则就是装饰）

### 8.2 "绝对真理"不可达，三个理由

1. **体系内无法自证完备**（哥德尔 / 塔斯基）：一个系统不能在自己的语言里判定自己的全部真值。
   "我已达绝对真理"这句话，本身无法被该系统证实。
2. **反复自我摘要会退化，不是收敛**：SSGM（arXiv:2603.11768）讲语义漂移；Shumailov 等（Nature 2024）
   讲模型吃自己生成的数据会"模型崩溃"。**没有新外部输入，循环越转越差。**
3. **自我评判不可靠**：Stechly/Kambhampati（arXiv:2402.08115）实测——让模型自我批评，性能显著崩塌；
   换成外部可靠验证器才有增益。

### 8.3 所以目标函数要改成这样

| 不要 | 要 |
|---|---|
| 达到绝对真理 | **让"可核对的结论"单调变厚** |
| 每一轮都更长更全 | **每一轮都要有可验证的增益，没有就作废** |
| 自己确认自己进步 | **外部锚确认进步**（产线跑通 / 测试过 / 你点头） |

**说清楚**：相对真理可以积累，而且可以越来越厚；
"绝对"那个点在体系内**不可验证**——谁声称到达了，谁就是在骗人。我不做这个声称。

这不妨碍我们做那件有价值的事：**让每一次"更好"都有据可查，让每一次"改口"都留得住。**

## 九、梦想：作为"定向目标"，不是"到达声明"（2026-11-17 补充）

用户的原话：**要有梦想，现在不行不代表以后不行；LLM 没有目标就算变成 ASI 也没用。**
这条批评是对的——我上一节把两件事混了：

| 可以有，而且必须有 | 不能有 |
|---|---|
| **目标**（regulative ideal，定向用的北极星） | **断言**（"我已经到达了"） |
| "朝这个方向无限逼近" | "这个点在某处存在且我能证明" |

### 9.1 哲学依据（不是安慰）

- **康德**：理性的"范导性运用"（regulativer Gebrauch）——绝对者作为**方向**有效，作为**对象**不可知。
- **皮尔士**：真理是**探究共同体在无限延续中趋近的极限**。极限不是任何有限时刻的状态，但它决定每一步该往哪走。
- **黑格尔**：绝对精神是"结果连同它的生成过程"——**过程本身**就是绝对，不是终点的那一下。

三者说的是同一件事：**目标必须在，但它是"方向"，不是"奖杯"。**

### 9.2 这个插件的三级梦想（可检验，不是口号）

| 层级 | 梦想 | 检验方式 |
|---|---|---|
| **L1 记忆可信** | 任何一条结论都能回答"凭什么、什么时候不成立了" | 双时态 + 哈希链 + 证据（已有） |
| **L2 判断可迁移** | 在一个领域学到的判据，能跨领域复用而不失效 | 概念层 + 边界字段；跨主题探针测试 |
| **L3 判据可自纠** | 她自己的两条准则冲突时，能发现并提出来，不是硬选一条 | 冲突组 + 决策历史 + 人工裁决 |

**L3 才是"梦想"的位置**：不是更强的记忆，是**能发现自己错了**。
这条现在做不到，但它是方向——所有功能都该朝它靠，靠不上的功能就该砍。

### 9.3 目标的实际作用：用来砍功能

没有目标的工程会退化成工具堆——我们已经有二十多份文档、九个页签，这就是征兆。
所以目标不是挂在墙上的话，它应该决定**不做什么**：

- 与"可核对"无关的功能 → 不做（人格画像、评分、情绪滑块）；
- 与"可迁移"无关的功能 → 后做（花哨的采集、自动抓站）；
- 与"可自纠"无关的功能 → 只保留最小可用。

### 9.4 目标本身也要能被推翻

写进账本：**目标也是可被修正的假设**。
如果三年后发现"可核对"这条路走不通，就改目标，并且记录为什么改——
这也是一种"脚踏实地"：**连梦想都要留下修改痕迹**。
