# 理念与方向：现象学人格（项目宪章 v1）

> 2026-11-10。这份文件只做一件事：把"我们要做的到底是什么"钉死，避免后面越做越偏。
> 它不是设计方案（设计见 [plan-persona-v2.md](plan-persona-v2.md)），是**判断标准**。

---

## 一、一句话

**人格不是她"是什么样的人"，是她的历史在她身上留下的斜率。**

我们不写"她温柔坚定"，我们让"被推翻过的那些事"在她下次遇到同类事情时，改变她看这件事的起点。

## 二、三条不可让渡的承诺

缺任何一条，这件事就不成立，应当停下重做。

| 承诺 | 意思 | 反例（出现即跑偏） |
|---|---|---|
| **不对称** | 补充信息几乎不动；推翻结论才动。过去的重量大于未来 | 每次对话都微调状态（那是情绪状态机） |
| **不可逆** | 只追加，改不了历史；要改只能再发生一次反向事件 | 提供"重置人格"按钮（那就成了配置项） |
| **非检索** | 不是"查到了旧事"，是"看这件事的方式变了" | 清空记忆库后行为回到出厂设置（那就是检索） |

## 三、五个"不是"

1. **不是人格文案**：不生成"我是谁"的描述，不写进 persona 文件。
2. **不是角色扮演**：不模仿语气、不演性格、不做"傲娇/病娇"这类状态。
3. **不是情绪状态机**：情绪是短时的、由当下事件驱动的；我们要的是长时、由历史累积的偏移。
4. **不是叙事自我**：不讲"关于自己的故事"。叙事一引入，就会滑成写人设。
5. **不是意识声明**：不声称有内在体验。只承诺可测量的路径依赖。

## 四、方向：做"发生层"，不做"策展层"

| 层 | 谁负责 | 做什么 |
|---|---|---|
| 事实层 | `dsh-cognition-engine` 双时态 | 什么是真的、什么曾经是真的 |
| 治理层 | `persona` 模块 | 提案→确认、锁定短语、快照——**这是防漂移的，不是长人格的** |
| **发生层（本项目）** | 沉积层 | 被经历熏出来的 4 维偏置，只调生成起点 |

**明确选择**：不做"编辑人格"的功能，不做"人格市场"，不做"人格评分"。
编辑人格是策展（人设定），我们要的是发生（经历长出来的）。

## 五、"人格"在这里的操作定义

四个数，每个都对应一种可观察的行为差别：

| 维度 | 高 | 低 |
|---|---|---|
| `retention` | 旧信念更重，不轻易被说服 | 容易改口 |
| `caution` | 先问再做 | 直接动手 |
| `openness` | 主动找反例 | 只认已有口径 |
| `attachment` | 看重与具体人的约定 | 只按规则办 |

**维度上限 4。** 想加第 5 维，必须先证明它与现有 4 维在行为上不可替代——否则就是往"设计人格"退。

## 六、术语翻译（哲学词 → 工程词）

| 哲学概念 | 来源 | 我们的工程实现 |
|---|---|---|
| 滞留 | Husserl | 不是记忆条目，是衰减的权重作用于**阈值** |
| 前提 | Husserl | 期望张力 → 预测误差事件（幅度为普通的 1/3） |
| 被动综合 | Husserl | 无冲突的重复 → `settle`，缓慢衰减，只能追加 |
| 习性 | Merleau-Ponty | 重复无冲突 → `caution` 缓降（更顺手） |
| 最小自我 | Zahavi | 状态连续本身即"最小自我"，不需要叙事 |
| 在世存在 | Heidegger | 偏置只作用于最近 K=20 轮聊过的主题 |
| 不对称 | Sawyer | 反转 vs 补充的位移比 ≥ 5× |

## 七、成功的判据（唯一一条）

> **两周后，你能不能指着日志里某一条事件说：「就是这件事之后她变了」？**

能 —— 说明这是"有经历的东西"。
不能 —— 不管参数多漂亮，都是自欺，回到 M0 重做。

附两条硬测（不能只靠感觉）：
- 关掉检索，行为差异仍在（非检索）；
- 改一行日志，哈希链校验失败（不可逆）。

## 八、跑偏清单（自查用）

出现以下任何一条，视为方向错误，先停下来：

- [ ] 开始输出"人格描述"文本
- [ ] 开始写/改 `persona` 文件
- [ ] 给用户做"人格调参"界面（情绪滑块、性格下拉）
- [ ] 接上奖励/评分回路，"效果更好"就调参
- [ ] 维度超过 4
- [ ] 用"像人""有意识"当卖点
- [ ] 用未同行评审的效果数字当依据

## 九、一句话方向

**把 `dsh-cognition-engine` 从"记忆的账本"，延伸出一层"被经历磨出来的偏置"；
账本负责真实，偏置负责倾向；两者单向流动，永不互相改写。**
