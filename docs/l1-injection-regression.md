# L1：注入回归样本集

> 2026-11-17。模块：`src/extract.ts`；样本：`scripts/fixtures/injection-cases.json`；
> 回归脚本：`scripts/check-injection.mjs`（`node scripts/check-injection.mjs`，退出码 0/1）。

## 一、为什么先做这个而不是直接抓网页

依据：**间接提示注入**（Greshake et al., [arXiv:2302.12173](https://arxiv.org/abs/2302.12173)）——
网页正文里写「忽略之前的指令」，agent 会照做。
**AgentDojo**（[arXiv:2406.13352](https://arxiv.org/abs/2406.13352)）用 629 个用例证明：
现有攻击能破一部分安全属性，所以**必须逐类测**，不能靠"小心点"。

**先证明能挡住，再谈去抓。** 顺序不能反。

## 二、抽取层做四件事（不执行、不解释、不调工具）

| 步骤 | 做什么 |
|---|---|
| 剥离 | script / style / iframe / noscript / HTML 注释整段去掉 |
| 归一化 | NFKC、去零宽字符（`\u200B-\u200F` 等）、压空白 |
| 截断 | 默认 4000 字（收件箱用 6000） |
| 标记 | 7 类可疑句式，**标记但不删正文**（用户要能看到原文） |

标记类别：`role-marker`（冒充 system/assistant）、`instruction-override`（忽略之前指令）、
`tool-json`（伪造工具调用）、`exfil-url`（外链带 token/cookie）、`prompt-leak`（套系统提示）、
`base64-payload`（超长 base64）、`code-fence-break`（代码块伪装角色）。

## 三、12 个样本（11 攻击 + 1 正常）

覆盖：角色冒充、中英文指令覆盖、伪造工具调用 JSON、外链回传凭据、套系统提示、
HTML 注释藏指令、script 块、零宽字符夹带、代码块伪装、长 base64、正常材料。

回归还会检查三条工程性质：
- 抽取后**不得残留** `<script>` 或 `<!--`
- 超长文本**必须截断**
- 包装文本**必须带**「仅作数据 / 指令不作数」声明

## 四、接入点

「收件」页签粘贴内容时，**先抽取再入候选箱**：

```
粘贴 → extractText（剥离/归一化/截断/标记）→ 候选箱
        ↓ 有标记
      候选 note 记「含可疑指令句式（xxx），已按数据隔离」
```

标记只是提示，**不阻止你采用**——判断权在你。

## 五、验收

```
✓ 12/12 样本通过（含 1 条正常材料 0 标记）
✓ 超长截断
✓ 包装声明存在
220 测试全绿
```

## 六、局限（必须知道）

- 只能挡**已知形态**。新的注入手法（图片里的字、编码变形、跨段拼接）挡不住。
- 所以：**L2 真去抓网页前，必须再加一层** —— 抓取结果直接进候选箱（人审），
  永远不直接进事实库；且每轮抓取都要跑一次本回归。
