# P4-3：子代理报告脱敏（规矩 + 扫描器）

> 2026-11-17。工具：`scripts/scan-sensitive.mjs`。这是**文档级约束 + 机器兜底**，不是运行时功能。

## 一、规矩（委派子代理时，把这段原话放进任务）

> 报告里只写**结论**和**可核对的出处**（链接、书名、论文号、文件路径的相对形式）。
> **不要粘贴任何私人内容原文**：站名、人名、地块/回路编号、具体读数、精确日期期次、
> 本机绝对路径、账号与凭据。
> 需要举例子时，用「某站」「某期」「一组读数」这类概括说法；宁可少写一个例子，不要多写一个真名。

## 二、为什么需要机器兜底

人会忘，模型更会忘。子代理写调研报告时最容易把"原文里很具体的东西"当成"证据"搬进来。
所以交付前扫一遍：

```powershell
node scripts/scan-sensitive.mjs <报告文件或目录>
# 或从管道读
Get-Content report.md -Raw | node scripts/scan-sensitive.mjs -
```

退出码：`0` 干净 / `2` 有命中。可以挂在脚本里当闸门。

## 三、它能抓什么（9 条规则）

| 规则 | 例子 | 建议 |
|---|---|---|
| 变电站名 | 某岭变电站 | 换「某站」 |
| 电压+站名 | 220kV 某岭 | 概括说 |
| 工程期次 | 2026工作 / 11.04期 | 用「某期」 |
| 手机号 | 138**** | 删 |
| 身份证 | 18 位（带生日校验，避免误判 DOI） | 删 |
| 邮箱 | a@b.com | 删/脱敏 |
| 凭据 | token= / cookie= / api_key= | 绝不外发 |
| 现场读数/回路号 | 越限 / 0.030A / 5412 回路 | 概括 |
| 本机路径 | `D:\Users\...` | 删 |

## 四、它抓不到什么（必须人看）

- **同义改写**的站名（"那个靠江边的站"）
- **纯数字编号**（如果它长得不像手机/身份证）
- **上下文敏感**：一段话单看没事，配上前一句就暴露了

所以：**扫描器只负责把明显的挑出来，过一遍人眼仍是必须的。**

## 五、首次全仓扫描发现的问题（已修）

| 位置 | 问题 | 处理 |
|---|---|---|
| `docs/bench-bm25/corpus.json` / `corpus_hard.json` 第 240 行 | 含本机绝对路径 `D:\minmaxgz` / `D:\dshgz` | 替换为 `D:\ws-old` / `D:\ws`；**重跑基准，结果与旧输出完全一致**（clean 与 hard 两套都是），说明脱敏没影响数值 |
| `docs/research-persona-hci-philosophy-npc.md` | DOI `10.1518/001872097778543886` 被误判成身份证 | 修规则：身份证必须带合法生日，DOI 不再命中 |

## 六、验收

- 合成敏感文本 → 9 条规则命中（单测断言）
- 干净文本 → 0 命中
- 全仓 `docs` 扫描 → **0 命中**
- 基准重跑 → 与脱敏前输出**完全一致**
