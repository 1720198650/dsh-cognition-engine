# 自动采集 + 自动学习：升级方案 v1

> 2026-11-11。带 M1（LLM 语义判定）落地后，回答「她自己去网上找资料 / 自己学」这块怎么升。
> 前置：[plan-hybrid-v4](plan-hybrid-v4.md)、[m0-findings](m0-findings.md)、[charter](charter-phenomenological-persona.md)。

---

## 一、先划线：三件事，只有两件能做

| 能力 | 能做吗 | 形态 |
|---|---|---|
| **自动采集**（自己去网上找资料） | ✅ 能 | 抓 → 摘要 → 进**候选箱** → 你点头才成事实 |
| **自动学习**（把读到的东西变成准则/技能） | ✅ 能，但**必须人批** | 只提候选，走现有准入闸门 |
| **自动改自己**（读到什么就改四维/改人设） | ❌ **不做** | 自我强化回路，且会毁掉"不对称"判据 |

第三条不是保守，是有机制的：她的采集会写新事实 → 若也算"翻案"，四维就会被**她自己读的东西**推动，
从此说不清哪次变化来自你的真实经历。判据当场失效。

## 二、依据（都是核实过的）

1. **间接提示注入**：网页正文里写「忽略之前的指令」，agent 会照做。
   Greshake et al., *Not what you've signed up for*, [arXiv:2302.12173](https://arxiv.org/abs/2302.12173)。
   → 采集到的正文只能当**数据**，不能当**指令**；必须隔离。
2. **攻击面是要测的，不是靠感觉**：AgentDojo 给了 97 个任务 / 629 个安全用例，
   指出**现有攻击能破一部分安全属性但不是全部**——
   [arXiv:2406.13352](https://arxiv.org/abs/2406.13352)（[项目页](https://agentdojo.spylab.ai/)）。
   → 我们要有自己的注入回归样本集，而不是"小心点就行"。
3. **自我批评不可靠**：Stechly / Kambhampati, [arXiv:2402.08115](https://arxiv.org/abs/2402.08115)；
   LLM-Modulo 主张 LLM 只当近似知识源、由外部验证器判收：
   Kambhampati et al., ICML 2024, [arXiv:2402.01817](https://arxiv.org/abs/2402.01817)。
   → 她"觉得自己学到了"不能当证据，要有**外部锚**（真跑一遍、有测试、有出处）。
4. **自我奖励会跑偏**：Self-Rewarding LMs（[arXiv:2401.10020](https://arxiv.org/abs/2401.10020)）、
   STaR（[arXiv:2203.14465](https://arxiv.org/abs/2203.14465)）都靠**可验证结果**才有增益，
   没有验证信号时退化成自我模仿。
5. **技能库比"重训自己"划算**：Voyager 用「可执行代码技能库 + 环境反馈 + 自验证」
   做到持续学习且不遗忘（[arXiv:2305.16291](https://arxiv.org/abs/2305.16291)）。
   → 我们要的"学习"应该是**积累可复用的做法**，不是改权重、更不是改人格。
6. **递归吃自己会崩**：Shumailov et al., *Nature* 2024 的"模型崩溃"——
   只用自己生成的数据训练，几代内输出退化。
   → 采集与学习都必须有**外部来源**占比；不许自己写、自己读、自己确认。

## 三、自动采集（自动刷）设计

```
主题 + 域名白名单
   → robots.txt 检查 → 单域名限速 → 抓正文
   → 剥指令句式（当数据）→ 摘要（≤200 字）
   → 与现有事实去重（相似度 ≥0.9 直接丢，记一条"重复已丢"）
   → 进候选箱（**不是记忆**，不参与召回、不参与注入）
   → 你「采用」→ 写事实层：source=web、可信度=低、带出处与抓取时间
     你「丢弃」→ 只留一条丢弃记录
```

**硬约束**
- 默认关闭；开启也只抓白名单域名。
- 单域名 QPS ≤1，尊重 `429 / Retry-After`，UA 写明用途，带联系方式域名。
- 每次抓取的 token 预算封顶；候选箱上限（比如 200 条），超了停止采集而不是覆盖。
- **「仅参考」标记**：采来的事实默认不能当"证据"参与冲突判定，只能用来说话——
  否则她读来的一段科普会变成"推翻你结论"的理由。

## 四、自动学习（她"学到了"）设计

学习只允许产出三种**候选**，全部需要人批：

| 类型 | 例子 | 去哪 | 批准方式 |
|---|---|---|---|
| 事实候选 | "这个库 0.9 的 API 变了" | 候选箱 → 事实层 | 面板勾选 |
| 准则候选 | "以后发版前先跑一遍真实入口" | 准则本 pending | 现有准入闸门 |
| 技能候选 | "抓 B 站视频帧要先装 ffmpeg" | 技能库（只追加） | 面板勾选 |

**外部锚（没有它就不许算"学会"）**：每条候选必须带**可核对的验证**
——原文链接、一次成功的真实调用记录、或一条测试结果。
只有模型自评「我学会了」→ 直接丢弃。

**频率与预算**：每天最多 N 次学习尝试；失败的也记录（只记失败比记成功更有用）。

## 五、和 M1（语义判定）的关系

新事实进库时**不触发**沉积层（沉积层只认"取代"）。
只有当**你**后来推翻了一条（采来的）事实，才可能触发一次 tension——
这样四维仍然只由真实经历推动，不被采集污染。

采集来的事实若被你自己改口推翻，判定通道照旧走 LLM 五分类，
但事件里要额外记 `origin: 'web'`，统计时能分开看"被网上的话改口"占比多少。

## 六、里程碑

| 阶段 | 内容 | 工作量 | 退出条件 |
|---|---|---|---|
| **L0** | 候选箱 + 面板采用/丢弃 + 采用后写事实层（不联网） | 1 天 | 你能审完 10 条不烦 |
| **L1** | 注入回归样本集（10 条畸形网页）+ 抽取器只当数据 | 1 天 | 10 条攻击样本全部不生效 |
| **L2** | 白名单抓取 + 限速 + robots.txt + 失败重试上限 | 2 天 | 抓 20 页不触发封禁；错误全部落日志 |
| **L3** | 自动学习三候选（事实/准则/技能）+ 外部锚校验 | 2 天 | 无锚候选 100% 被拒 |

**L0 是闸门**：如果你一周都懒得审 10 条，就别做 L2——自动抓 200 条只会变成垃圾场。

## 七、红线

1. 采集不产生熏习，四维只由**你**的翻案推动。
2. 不许自动采用自己的输出；候选必须过人。
3. 自评不算证据，必须有外部锚。
4. 不越 robots、不绕限速、不伪装 UA。
5. 采来的内容默认"仅参考"，不可作为冲突判定依据。
6. 一旦发现她在"引用自己写的笔记"当证据 → 立即停采，排查回路。
