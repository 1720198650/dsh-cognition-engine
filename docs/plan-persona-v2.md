### 所以“原创”到底剩什么（不吹）

**不是原创的**：慢变量偏置（Pae）、只追加因果链（yogacara）、事件-观察-状态分离（AutoPersonas）、长期一致性的工程化（ARPM）。

**目前没看到别人做的三条**（也要接受被推翻的可能）：
1. **哈希链**把“不可逆”变成结构性事实（改一行后面全断），而不是靠纪律；
2. **反事实重放 + 检索消融**作为验收标准（关掉检索差异仍在才算数）；
3. **4 维、每维定义行为极性**，并把维度上限写成不可扩张的约束。

## 二、从先行工作里吸收的四条硬结论

1. **纯语义检索不够**（ARPM 消融：关掉对话历史检索 100%→66.7%，关掉 BM25 →80%）。
   → 我们的偏置层**不能替代检索**，它只调"起点"；同时记忆侧必须保留关键词通道。
2. **自动判定会低估**（ARPM：自动召回 54% vs 人工 100%）。
   → 我们的验收要分「自动指标」与「人工抽查」两栏，不许只报自动的。
3. **长期一致性是可分解的治理问题**（ARPM 的核心主张），不是玄学。
   → 我们把"人格"拆成 4 个可测参数，符合这个方向。
4. **未同行评审的效果数字不作依据**（Melissa 的 10+ 复现、97.1% 相关；Project Sue 的效果）。
   → 只借结构，不引数字。

## 三、设计（v2）

### 3.1 三层边界不变

```
事实层  dsh-cognition-engine  真的/曾经真的（双时态）
治理层  persona 模块          提案→确认、锁定短语（不动）
发生层  沉积层（本方案）       只输出 4 维偏置，不产文本、不改事实
```

### 3.2 数据：哈希链轨迹 `cognition-sediment.jsonl`

```json
{"seq":12,"at":1794318397354,"kind":"tension","subject":"部署区域",
 "from":"mem-1a","to":"mem-3f","tension":0.71,"flip":1,
 "delta":{"retention":0.02,"caution":0.03,"openness":-0.01,"attachment":0},
 "prevHash":"9f2c…","hash":"a71b…"}
```

`hash = sha256(prevHash + 规范化事件体)`。事件四类：`tension` / `protentionError` / `settle` / `manual`（需理由）。

### 3.3 状态：4 维，每维给行为极性

| 维度 | 高 | 低 |
|---|---|---|
| `retention` | 更少被新说法说服 | 容易改口 |
| `caution` | 先问再说 | 直接给结论 |
| `openness` | 主动找反例 | 只认已有口径 |
| `attachment` | 更看重与具体人的约定 | 只按规则办 |

硬上限 4；要加第 5 维必须先证明它与现有 4 维行为上不可替代。

### 3.4 熏习规则（唯一入口，含证据绑定）

```
tension = sim(old,new) × flip
  flip: 否定/反义命中 = 1.0；语气弱化 = 0.5；纯补充 = 0
  tension ≥ 0.45 才记事件
delta = η × tension × direction；η = 0.02（单次最大 2%）
每维夹 [0,1]；同维只增不减；回滚也必须作为新事件追加并标记
```

**证据绑定（借 ARPM 的“证据校验”思路）**：每条 tension 事件必须存 `from`/`to` 两个事实 id；
没有双 id 的事件拒绝写入——防止以后回溯时说不出“凭什么变的”。

### 3.5 参与生成（非检索的工程保证）

在 recall **之前**运行，只输出参数：

1. `retention` 高 → 收紧 strict 阈值（新证据更难覆盖）；
2. `caution` 高 → 注入里"先确认再动手"的权重提高（不改语义内容）；
3. `attachment` 高 → 同人/同项目记忆排序加权；
4. 作用域：只对最近 **K=20 轮**出现过的 subject 生效，其余中性（在世存在）。

**它不读记忆正文。** 事实库清空，参数仍在——这是非检索的判据基础。

### 3.6 预期与巩固（v1.1 保留）

- `protentionError`：期望张力 = 最近 10 次同主题均值；偏差 > 0.2 记一次，幅度 1/3。
- `settle`：同主题连续 ≥8 轮无 tension，`retention *= 0.995`（地板 0.2）。

## 四、验收（先写协议，再写代码）

| # | 断言 | 通过条件 |
|---|---|---|
| A | 路径依赖（不对称） | 补充类事件几乎不动；反转类事件的 Δ 范数是其 ≥5 倍 |
| B | 不可逆 | 任意事件被改动 → 哈希链在改动点之后全部校验失败 |
| C | 非检索 | 同一情境在 checkpoint 10/20/30 决策互不相同；**强制 recall 返回空后差异仍在** |
| D | 惊奇≠张力 | 相似但不矛盾（flip=0）→ 允许 protentionError，`retention` 必须不变 |
| E | 自动 + 人工双报 | 自动指标之外留人工抽查栏（ARPM 教训：自动会低估） |
