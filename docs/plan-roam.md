# 漫游功能计划（2026-11-19）

> 用户原话：拟做一个漫游功能，让你说话是个人；学习只是让你工作是个人；但这两都链接到人格。
> 还要求：**得会看视频再看评论，不然不知道语境**。参考大肥鱼刷 B 站 / QQ / 贴吧的插件。

---

## 一、先把两件事分清楚

| | 学习线 | 漫游线 |
|---|---|---|
| 目的 | 工作像专业人士 | 说话像个人 |
| 数据 | 论文 / 文档 / 网页 | 视频 + 弹幕 + 评论 |
| 产出 | 事实、准则、立场 | 语感、在场感、心情 |
| 验收 | 该记的记住、该做的做对 | 别人听不出是机器 |

**两条线都写回同一个「人格」，但严格不互通**：工作学的准则不能变成说话腔调，
漫游学的腔调**绝对不能**当事实用。这不是洁癖，是前面 AWM 那篇的教训——
错误经验混进来以后分不出好坏，越学越差。

---

## 二、看视频：四级，只做前三

实测（2026-11-19，本机直连）：

| 层 | 内容 | 接口 | 实测 | 成本 |
|---|---|---|---|---|
| L0 | 标题 / 简介 / 分区 / 时长 / UP主 | `x/web-interface/view` | ✅ code=0 | 免费 |
| L1 | **弹幕** | `x/v1/dm/list.so?oid=cid` | ✅ 200，112KB/视频 | 免费 |
| L2 | 字幕 | `x/player/v2` | ⚠️ code=0，但这条视频 0 条字幕轨 | 免费（有则用） |
| L3 | 评论 | `x/v2/reply` | ✅ 已验证，ps≤20 | 免费 |
| L4 | 关键帧抽图 | 需下视频 + 视觉模型 | 未做 | **贵一个数量级** |

**结论：L0+L1+L2+L3 拼起来就能懂语境，不做 L4。**
弹幕里大量「左边那个」「这表情」「前面说的」这类复述，画面信息被观众翻译成文字了。

**为什么必须先看视频再看评论**：单看评论会误解。
例：「其实延期发售就是为了等布鲁斯考到驾照」——不看在讲 GTA6，根本不知道在说什么。
样本必须带语境（视频标题 + 主题），否则学到的句子没法迁移。

## 三、架构：一脑两线

```
人格（persona，唯一真相）
 ├─ 学习线：资料层 → 事实/准则/立场 → 工作判断
 └─ 漫游线：视频语境 → 语感样本/在场 → 说话方式
```

新增与改动的模块：

| 模块 | 作用 | 复用现有 |
|---|---|---|
| `src/roam.ts` | 漫游调度：选视频、抓语境、提炼样本 | 新增 |
| `src/voice.ts` 扩展 | 样本增加 `context`（视频标题/分区/弹幕摘要） | 已有，加字段 |
| `src/voice_source.ts` 扩展 | 加弹幕、字幕、视频信息三个抓取 | 已有，加函数 |
| `src/mood.ts` | 心情/在场状态（大肥鱼那套） | 新增，后期 |
| 注入 | 语感段带语境，不再裸句 | 已有，改渲染 |

**语感样本的新结构**（关键改动）：

```ts
interface VoiceSample {
  text: string;        // 句子本身
  context: string;     // 这句在什么语境下说的（视频标题+分区+弹幕氛围）
  kind: 'comment' | 'danmaku' | 'reply';
  likes: number;
  url: string;
}
```

没有 `context` 的样本不许注入——这是"看视频再看评论"的硬约束。

## 四、漫游循环

```
选题材（兴趣/热榜/指定） → 抓 L0-L3 → 形成语境包
   → 从弹幕和评论里挑 2~3 句"这个语境下人会这么说"
   → 写进语感库（带 context）
   → 注入（≤120 字）
```

**不做的**：不发评论、不点赞、不投币、不登录、不运营账号。
（`dsh-bili-scroll` 那种"独立运营账号"明确不做，理由见正文：对外发言不可逆。）

## 六、分期

### P0（本次，1 天）
1. 抓取扩展：视频信息 + 弹幕 + 字幕（有则用）
2. 语感样本加 `context` 字段，无 context 不注入
3. 抓取时先取语境再取评论，样本自动带上下文
4. 验收：取一个视频 → 样本里能看到"这句是在什么视频下说的"

### P1（0.5 天）
1. 漫游入口：面板填 BV 号或选分区热门，一键"逛一条"
2. 一次产出 3~5 条带语境样本
3. 验收：不同分区各取一条，注入的句子风格明显不同

### P2（1 天）
1. **防复读**：句首前缀去重、高频词冷却、口癖检测
2. 验收：连续 10 轮说话，句首不重复、不出现固定口癖

### P3（待定）
1. QQ 本地导出语料（需用户给文件，先看实际格式）
2. 贴吧/知乎：匿名访问 403，**不做绕过**

## 七、风险与边界

1. **弹幕噪音极高**：脏话、复读、刷屏。筛选要比评论更严（现有 6 道筛 + 弹幕专用规则）。
2. **语境失真**：弹幕只反映"观众反应"，不等于"视频内容"。所以 `context` 里必须同时有视频标题，不能只有弹幕。
3. **成本**：抓取免费，提炼要模型调用。一条视频约 ¥0.01~0.02，可接受。
4. **不越界**：只读公开接口、不登录、不互动、不运营账号。
5. **人格不被污染**：漫游线产出只能进语感库，**永远不进事实库和准则库**（代码层面隔离）。
