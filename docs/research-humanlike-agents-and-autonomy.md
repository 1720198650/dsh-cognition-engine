# 拟人化 Agent、自动刷 B 站与 LLM 自主学习研究

> 记录：2026-11-05
> 起因：想弄清「AI 自动刷 B 站 / 接 QQ 的机器人为什么像人」，以及它们到底在学什么。
> 关联：[research-super-agent-and-persona.md](research-super-agent-and-persona.md)

---

## 一、为什么这些 bot「像人」

### 1.1 五个机制，按贡献排序

| # | 机制 | 作用 | 代表实现 |
|---|---|---|---|
| 1 | **人设卡（persona）** | 决定语气、句长、口癖、边界。同一个模型换人设 = 换一个人 | MaiBot 的人设库（`maibot.personality` JSON）、Letta 的 persona block |
| 2 | **关于你的记忆** | 记住名字、偏好、旧事，在合适的时候提起来 | MaiBot A-Memorix、Letta human block |
| 3 | **发言时机** | 不该说时闭嘴，该说时短说。**这比内容更像人** | MaiBot `turn_trigger`、`focus` 模式 |
| 4 | **风格模仿** | 学群友的新词、黑话、句式，再复用 | MaiBot `expression_learner.py` |
| 5 | **刻意的不完美** | 短句、停顿、偶尔口语化，而不是长篇分点 | 各家 prompt 里都写 |

**关键：这五条没有一条需要「意识」或「情感」。**
它们是 prompt + 检索 + 规则 + 一点统计，组合出来的**行为拟真**。

### 1.2 一个反面参照：Bilibili Agent MCP

它的设计立场写得很清楚：

> **「做工具不做替身」**——不带人格、不另开一个代替你的智能体、不要求它每天必须浏览或自动社交。
> 主智能体决定看什么、做什么，MCP 只提供观察材料。

同样是接 B 站，它选择**不做人格**。这说明「像人」是一个可选的产品决策，不是技术必然。

### 1.3 边界：像人 ≠ 是人

- 它没有连续的主观体验；「记得你」是检索出来的，不是「想起你」
- 它的「情绪」是 prompt 里写的表达规则，不是内部状态
- 它的「性格」是稳定的输出偏置，不是欲望
- **不要因为输出像人就推断它有内心**——这是拟人化最大的认知陷阱

## 二、刷视频时在学什么

### 2.1 dsh-bili-scroll 的真实流水线

（1213★，MIT，2026-11 活跃）

```
按你填的关键词搜近几天的视频
  → 逐条读字幕原文（不看摘要）
  → 没字幕的演示类视频，从 B 站故事板抽几帧看画面
  → 实在读不到内容才跳过（或开本地转写）
  → 写 Markdown 日报：每条含「为什么值得」+「它自己的一句话」
  → 开着自动评论时，每轮发一条评论 @ 你
  → 可配置峰谷时段自动跑，省 token
```

**它「学」了什么？**

| 说法 | 实际 |
|---|---|
| 「按你的口味刷」 | 主要是**你填的关键词 + 设置页的 20 个开关**，不是模型自己悟出来的 |
| 「读字幕判断」 | 是**推理**（读文本 → 判断相关性），不是**学习**（不更新权重） |
| 「越刷越懂你」 | 如果有，也只是**历史记录 / 收藏 / 反馈**被写进下次的上下文 |

**结论：它是「过滤器 + 摘要器」，不是「学习者」。**
所谓「口味」是你配置出来的，不是它训练出来的。

### 2.2 三种「学习」的真相

| 类型 | 刷视频时有没有 | 说明 |
|---|---|---|
| **参数学习**（改权重） | ❌ 没有 | 没有训练，模型不变 |
| **记忆学习**（写外部状态） | ⚠️ 可能有 | 看过/收藏/不喜欢 → 下次过滤；但不一定实现 |
| **上下文学习**（临时） | ✅ 有 | 这一轮读了字幕，下一轮就忘了 |

### 2.3 Bilibili Agent MCP 的 35 个工具

GPL-3.0，工具覆盖：首页推荐、视频观看、弹幕评论、用户主页、收藏、私信。
视频理解走「音轨上传 + 千问 Omni 多模态」。

它的定位同样是**给已有 agent 提供「B 站信息输入」**，不自己做人格、不自动社交。

### 2.4 一句话

> **刷视频的 AI，绝大多数在「看」，不在「学」。**
> 它把非结构化的视频变成结构化的文字判断，交给你的 agent 用；
> 真正的「学习」发生在你的 agent 把判断写进记忆之后——而且那也只是记忆，不是能力。

## 三、聊天时在学什么

### 3.1 MaiBot 的四个机制

（6.9k★，Python，主打 QQ 群聊「数字生命」）

| 机制 | 做什么 |
|---|---|
| **自然对话风格** | 不堆长篇，长短结合，像群里的人 |
| **A-Memorix 记忆引擎 + 人格画像** | 记住每次交流；结合心理学人格模型 |
| **智能发言时机** | `turn_trigger` / `focus` 模式：读气氛，该说才说 |
| **表达学习** | `expression_learner.py`：模仿群友的说话风格、新词、黑话，写入向量索引复用 |

**它学的是「怎么说」，不是「是什么」。**
事实/偏好靠记忆，风格靠表达学习，人格靠角色卡。

### 3.2 可控记忆的四层拆分（实战项目）

一个 NoneBot2 + NapCatQQ + DeepSeek 的 QQ bot 项目，把「记忆」拆成四层：

```
第一层：短期原文        —— 最近几轮对话
第二层：会话摘要        —— 压缩较旧的聊天
第三层：主人手动长期记忆 —— 只保存主人明确添加的事实/偏好
第四层：语义索引        —— 暂不启用
```

**核心原则：**

- **会话摘要不是长期记忆**。它只回答「之前这段聊过什么」，不能变成用户画像
- **长期记忆只允许主人手动添加**（`/添加事实记忆`、`/添加偏好记忆`）
- 不让 AI 自动从闲聊里提取长期记忆——否则「今天累了」会变成「用户长期疲惫」

### 3.3 角色卡只控制表达，不保存记忆

| 角色卡负责 | 角色卡不负责 |
|---|---|
| 称谓、语气、回复长度、表达习惯 | 保存用户事实 |
| 主人/非主人模式 | 保存用户偏好 |
| 什么时候简短、什么时候给步骤 | 记录项目进度 |
|  | 替代会话摘要 |

**人格和记忆必须分开**，否则会出现「把角色卡当记忆」或「把记忆当人设」。

### 3.4 上下文组装顺序（很关键）

```
1. 基础系统提示词
2. 通用底层聊天协议（身份/权限/隐私/安全）
3. 当前角色卡
4. 当前发言者身份上下文（主人 / 非主人，由系统判定）
5. 主人公开信息规则
6. 主人手动长期记忆
7. 当前会话摘要
8. 最近短期原文
9. 用户本次消息
```

原则：
- 安全/权限 > 角色卡
- 角色卡 > 普通表达习惯
- 长期记忆不能覆盖当前消息
- 会话摘要不能覆盖短期原文
- 当前消息优先于旧上下文

### 3.5 结论

> **聊天时学的是三样：会话摘要（说过什么）、手动长期记忆（关于你的事实/偏好）、表达风格（怎么说）。**
> **不学人格本身**——人格是角色卡，是配置，不是从聊天里自动长出来的。

## 四、LLM 自动行动与学习的论文 / 项目

### 4.1 自动行动：从 ReAct 到 Super-agent

| 阶段 | 代表 | 核心机制 |
|---|---|---|
| 2022 | **ReAct** | 推理与行动交替：Thought → Action → Observation |
| 2023 | **Reflexion** | 失败后写自然语言反思，下一轮带上 |
| 2023 | **Voyager** | 技能库：验证过的行为存成可复用代码，自动课程 |
| 2023 | **Generative Agents** | 记忆流 → 反思 → 计划；recency/importance/relevance |
| 2023 | **MemGPT** | 虚拟上下文管理：主上下文 + 外部记忆 + 分页 |
| 2023 | **AutoGPT / BabyAGI** | 自主循环、任务分解（第一代，工程上不成熟） |
| 2024 | **OpenHands** | 开源 agentic SDLC 平台；GitHub/Slack/Jira/定时触发 |
| 2025 | **UI-TARS** | 端到端 GUI agent（字节） |
| 2026 | **SEAgent** | 自进化 computer-use agent：World State Model + Curriculum Generator + GRPO |
| 2026 | **DeepSeek Super-agent** | Router + Worker + Ticket + 授权 + 主动观察 + Watchdog |
| 2026 | **Agent Zero** | 自主 agent 框架、computer use、A2A、状态回滚 |

**成熟度的分水岭**：
- 2023 年的 AutoGPT 类：能跑，但不可控、容易跑偏
- 2024–2025 年的 OpenHands / UI-TARS：有明确任务边界和评测
- 2026 年的 Super-agent：把「授权 / 工单 / 人工交接 / 注意力成本」当成一等公民

### 4.2 学习：四层 + 三条路线

| 层级 | 机制 | 改权重 | 代表 |
|---|---|---|---|
| L1 上下文学习 | prompt 示例 | 否 | few-shot / ICL |
| L2 记忆学习 | 外部记忆 + 检索 + 反馈 | 否 | ExpeL / ReasoningBank / ACE / 我们 |
| L3 工具自造 | agent 写代码训练另一个模型 | 否 | 聊天记录里的外挂 |
| L4 权重更新 | 微调 / GRPO | **是** | SEAgent |

**L2 的三条路线：**

1. **经验提炼**：ExpeL（成功/失败轨迹对比 → insight）、Reflexion（失败反思）
2. **技能库**：Voyager（可执行代码技能）、AWM（工作流）
3. **上下文工程**：ACE（bullet + 计数 + delta）、Dynamic Cheatsheet（分节 + 预算）

### 4.3 记忆的三类划分（2026 综述）

来自 *A Survey of Agent Memory in the Second Half*（TMLR 2026）与
*From Storage to Experience*（ACL 2026）：

| 维度 | 取值 |
|---|---|
| **记忆基质** | 参数化（权重） / 外部检索（向量、JSON、图） |
| **认知机制** | 感觉 / 工作 / 情景 / 语义 / 程序 |
| **记忆主体** | 用户中心（个性化） / agent 中心（自身经验） |

核心观点：

> 记忆不只是被动存储，而是 **agent 自我进化的基质**：
> 短期记忆决定「感知到什么、抽象出什么」，长期记忆把它固化成可复用的知识与技能。

### 4.4 拟人化的警告：人格会崩

**《Best Friends, Not Forever》**（Salesforce AI Research，arXiv 2607.28818，2026-07）

- 2,008 段对话 / 27 个人设 / 9 种交互日程 / 3 种记忆设置 / 4 个模型
- **轨迹准确率平均只有 44.4%**（四选一）
- **用户状态回忆接近随机**（0.214–0.250）
- 没有任何上下文或记忆配置能稳定解决
- 人格保持度因模型、人格维度、评估者而异，且与逐轮行为不一致

结论：

> 当前系统**还不能可靠支持长期的人格连续性**。
> 「有性格」不是写一段 prompt 就完事，需要状态管理 + 审计。

## 五、对我们插件的启示

### 5.1 我们已经有的

- ✅ 长期记忆（双时态 + 主题 + 准则 + 缺口）
- ✅ 证据链 / 来源分级 / 冲突裁决
- ✅ 主动闸门（`proactive.ts`，默认 record-only）
- ⚠️ 但没有「人格块」、没有「表达学习」、主动闸门没接火

### 5.2 该抄的

| 来源 | 抄什么 | 落到哪 |
|---|---|---|
| **Letta** | persona block + human block | `cognition-persona.json` |
| **MaiBot** | 发言时机（turn_trigger）+ 表达学习 | `proactive.ts` 接火；`expression` 表 |
| **Juejin 四层拆分** | 短期原文 / 会话摘要 / 手动长期记忆 / 角色卡 分离 | 我们的 memory / playbook / persona 分区 |
| **dsh-superagent** | record-only + 白名单 + Ticket | 主动行动的三道刹车 |
| **SEAgent** | 逐步世界状态评估 | 映射到 `appliedGood/appliedBad` |
| **Persona Collapse 论文** | 人格审计指标 | 人格块变更历史 + 定期自检 |

### 5.3 不该抄的

- ❌ 自动从闲聊里提取「人格」——会把临时状态写成永久人设（Juejin 明确警告）
- ❌ 自动从聊天里提取「长期事实」——同上
- ❌ 为了「像人」故意加错别字/情绪表演——短期有效，长期失真
- ❌ 无审批的自动社交/自动评论——dsh-bili-scroll 自己都要防提示注入

### 5.4 关键判断

> **「像人」的本质是「稳定的表达 + 恰当的记忆 + 合适的时机」，不是「有内心」。**
> **「学习」的本质是「把经验写进可检索的外部状态」，不是「模型变聪明」。**
> **「自我行动」的本质是「有边界的主动」，不是「无限制的自主」。**

---

## 六、一句话总结

> 那些 bot 像人，是因为**人设写得好、记忆记得住、时机把握准、风格模仿像**——四件工程事，没有一件需要意识。
> 它们在「学」的，是**关于你的记忆**和**怎么说话**，不是**能力**。
> 真要让能力变强，只有 L4（训练）——那是另一条路，不是插件能做的。
